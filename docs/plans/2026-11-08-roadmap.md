# Mobile Flashcards roadmap

Created: 2026-11-08

Status: Planning. Nothing below is built yet.

Owner: Chidi Orji <orjichidi95@gmail.com>

## How this document is used

A checklist of what we haven't done. Tick an item when it ships; split an item into its own plan file once we start designing it. Ideas are one line until then.

---

## 1. Ideas from the owner

- [ ] **LLM plugin to export a quiz.** Hand a deck (or part of one) to an LLM tool and get a quiz back. Builds on the deck JSON format and the AI prompt we already ship.
- [ ] **Alarms to take a quiz.** Local reminders at times the user sets, opening straight into a deck's quiz.
- [ ] **Quiz plans and recap plans.** A schedule for what to quiz and when to recap, per deck or across decks.
- [ ] **Add a backend.** Sync and accounts. Needs a design first: what is stored, what stays on device, and what it costs to run.
- [ ] **Study area.** Short key-point notes beside the cards. Hard limit on size so it never turns into a textbook: key points only.
- [ ] **On-device AI to create quizzes.** See section 3 for what the research found.
- [ ] **Link to quiz.** Give it a link and get quizzed on the page.

## 2. Carried over from earlier work

- [ ] **Tags and groupings for decks.** Builds on `deckOrder`. Design with the owner before building.
- [ ] **Bring-your-own API key** for AI deck generation, so there is no server to ship.
- [ ] **Multiple-choice cards.**
- [ ] **Formula rendering** in cards.
- [ ] **Android verification** of everything since 1.2.0: the drawer and hardware back button, the adaptive icon, the splash crop, dark-mode code blocks.
- [ ] **Store release.** Bump the version past 1.2.0, run the production Android build, submit to Play. The 1.2.0 build was never submitted.
- [ ] **iOS clipboard.** If pasting a deck on iPhone still returns empty, switch to expo-clipboard's `ClipboardPasteButton`.
- [ ] **Document import** (AI-assisted). Parked and disabled in the Import screen.

## 3. Notes

- **On-device AI (research, not built).** Apple Foundation Models via community Expo modules; Gemini Nano on Android is alpha; ExecuTorch and llama.rn can run small open models. Recommendation so far: deprioritise until these mature.
- **Link to quiz** needs a way to fetch and read a page, which points to either a backend or the user's own API key.
- **Quiz plans, alarms and a backend** overlap: reminders can be local-only, but sync across devices needs the backend decision first.

## Open questions
