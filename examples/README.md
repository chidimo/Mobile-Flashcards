# Example decks

Importable decks that show what cards can contain. Import them on the **Import deck** tab:

- **Choose file**: pick the `.json` file (save it to the device first, e.g. via AirDrop or Files)
- **Paste a deck instead**: copy the file's contents, then paste

| Deck                                               | What it is                                                                   |
| -------------------------------------------------- | ---------------------------------------------------------------------------- |
| [`css-flexbox.json`](css-flexbox.json)             | 15 cards on CSS flexbox, with `css` and `html` code in questions and answers |
| [`markdown-showcase.json`](markdown-showcase.json) | 7 cards showing `js`, `ts`, `python`, `sql`, `json`, lists, links and quotes |

Both fields, `question` and `answer`, (and the optional `hint`) are Markdown. Tag a code fence with its language (` ```css `) and it is syntax highlighted.
